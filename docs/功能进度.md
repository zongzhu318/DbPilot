# 功能进度与验收边界

当前版本：0.3.0。“已实现”表示存在可使用的界面和业务逻辑；离线检查不代表通过真实服务器验收。

| 模块 | 已实现 | 范围与待验证项 |
| --- | --- | --- |
| 连接 | 四库配置、测试、SSL、SSPI、超时、连接池设置、连接/断开、60 秒探测 | 操作独立管理连接；状态代表最近探测结果。真实认证、TLS、断网待验证 |
| SSH | 密码/私钥、口令、SHA256 指纹固定、动态端口转发与资源释放 | 未验证指纹拒绝连接；握手和私钥格式待实机验证。SSH + TLS 仍要求证书匹配端点 |
| 配置备份 | 口令派生密钥、AES-GCM、连接/分组/模板导入导出 | 导入追加连接，不覆盖现有连接；不含数据库数据 |
| 导航 | 分组管理、拖动换组、展开加载、Schema/类型分组、过滤、字段/标签子树、PG 例程签名 | 大量对象、特殊权限待实库验证 |
| 对象元数据 | 表/视图/索引/主键/默认值/生成列/外键；MySQL 例程与触发器；PG 例程与序列定义 | PG/SQL Server 表定义按基础元数据重建，不完整还原分区、存储、权限与全部约束 |
| 编辑器 | 多页、排序、高亮、快捷键、取消、格式化、脚本读写、未保存提示、FROM/JOIN 字段补全 | 基础补全与格式化，不是完整 SQL 语法树分析器 |
| 脚本/结果 | MySQL DELIMITER、PG dollar quote、SQL Server GO/GO N、出错停止/继续、源行定位、多结果切换 | 保留至多 100 项批次记录并保留首个失败；单批次最多 64 MB。成功批次不自动回滚 |
| 执行计划 | EXPLAIN、SQL Server SHOWPLAN_TEXT、独立只读结果页 | 不启用 ANALYZE；无图形成本树 |
| 浏览/编辑 | 四库分页、排序、复制、字段详情、多行文本/时间值编辑；主键关系表暂存增删改、参数化事务、并发校验、不确定提交保护 | OFFSET 受并发变化影响；TDengine 不提供关系型事务；特殊类型/触发器/RLS 待实测 |
| 导入导出 | 当前结果 CSV/JSON/SQL、整表流式 CSV/JSON、后端整表 SQL、CSV 映射与类型转换、TDengine 分批写入 | CSV 首行为标题，NULL 为 `\N`，前导反斜杠转义；关系型整批事务；TDengine 无跨批次回滚 |
| DDL | 表/视图/索引创建删除、增删改字段、SQL 预览并载入连接、删除二次确认 | 生成可审阅 SQL；复杂类型与专属约束需在 SQL 中补充 |
| TDengine | 超级表/子表/标签、子表归属分组、超级表/子表/标签/TTL 设计、时序模板、折线图、流/主题/订阅元数据探测 | 能力依赖服务器版本与权限；不含消息消费客户端。整表分页读取受并发变化影响 |
| 结构比较 | 字段类型映射、字段/默认值/NULL/主键差异、风险标记、目标 SQL 预览 | 不包括索引、分区、触发器与权限的完整差异同步 |
| 数据迁移 | 两连接间同名可写字段流式追加、类型转换、事务/进度/取消 | 目标表需先存在，可用设计器创建；生成字段由目标生成，不复制源自增值 |
| ER 图 | 真实表/字段/主键/外键、复合引用、滚动关系图、SVG | 单库最多 100 张表；不猜测关系 |
| 查询构建 | 字段勾选、类型化筛选、排序、行数限制、方言 SQL | 单表构建；复杂联表可在编辑器扩展 |
| 逻辑备份恢复 | 基础字段/计算列/主键/外键与数据、SQL Server identity、PG 序列恢复、脚本流式恢复 | 不含索引、唯一/CHECK 约束、视图、触发器、用户、权限、分区/存储；非服务器完整备份、非跨表一致性快照。MySQL 保留原库限定名 |
| 图表 | 时间/数值 X 轴、数值 Y 轴、NULL 断线、悬停、缩放、SVG | 使用当前结果及其截断限制，不插入演示数据 |
| 历史/模板 | 200 条成功查询、搜索、上下文恢复、内置/自定义模板增删改、加密保存 | 自定义模板不覆盖内置模板；历史载入后手动执行 |
| 设置/日志 | 主题、字体、字号、行号、换行、快捷键、窗口/分栏记忆、Info/Warn/Error、500 条加密日志 | 可关闭或清空；非长期服务器审计日志 |
| 发布 | Windows x64 包、六种 RID 发布脚本、Windows/Linux/macOS CI | 工作区实际构建 Windows；其他平台实机、签名、公证与远程 CI 待验收 |

## SQL 智能提示（2026-10-18）

- 输入至少两个字符自动提示；别名或 Schema 后输入点触发字段/表建议；Ctrl+Space 可手动触发。方向键选择，Tab/Enter 接受，Esc 关闭。
- 使用当前查询页的连接与数据库，关键字和常用函数区分四种方言；读取真实表/视图与字段类型、注释，按 FROM/JOIN/UPDATE/INTO 识别别名，支持 FROM 位于光标之后。特殊字段名插入时引用。

## 数据库选择与对象管理（2026-10-18）

- 连接右侧新增数据库下拉框与刷新入口；当前查询页使用所选数据库连接，支持不带数据库名的查询，各页独立保留上下文，新查询继承当前数据库。双击数据库同步选择；未提交/提交结果未知时阻止切换。
- 工具栏和树右键提供打开/关闭连接；关闭取消任务、清除已使用数据库的连接池、重置树节点，并阻止执行/元数据/DDL/自动字段读取；可重新打开。连接状态是逻辑开关与最近探测，非永久占用连接。
- 新建数据库表单预览并执行建库 SQL；新建表支持字段网格、主键、自增、NULL、默认表达式及预览，直接创建并刷新对象树。
- 对象树右键可删除/重命名表，删除确认，重命名/删除保护所有该表编辑草稿，成功后使旧浏览页失效。TDengine 不支持表重命名，明确提示；SQL Server 尚无实库环境。
- FROM/JOIN/UPDATE/INTO 后提示表；SELECT/WHERE/ON/SET/GROUP BY/ORDER BY 后提示字段及关键字，别名点号限制字段，FROM 空格可自动弹出。复杂 CTE/子查询作用域仍有限制。
- MySQL/PostgreSQL/TDengine 实库：通过新建库表、选库后的无库名查询、删除与关闭/重新打开；MySQL/PG 重命名保留数据通过。全部随机测试库均清理。报告 artifacts/catalog-live-report.json。

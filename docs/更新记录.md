## SQL 智能提示 · 2026-10-18

- 输入两个字符或别名/Schema 后的点自动触发补全，保留 Ctrl+Space 手动提示，支持方向键选择、Tab/Enter 接受、Esc 关闭。
- 根据查询页连接提供方言关键字、函数名、当前数据库表视图和 FROM/JOIN/UPDATE/INTO 引用字段；别名点号限制到对应表字段，Schema 点号提示表。
- 支持字段类型/注释说明和特殊名称引用，避免在字符串/注释/dollar quote 中触发。按语句隔离引用，不解析复杂 CTE/子查询作用域。
- 后台元数据独立连接，250ms 防抖、60 秒缓存、请求超时与失效取消，避免干扰执行中的查询。

## 0.3.0 · 数据库工具

- 接入多结果集和流式脚本执行，支持 MySQL DELIMITER、PG dollar quote、SQL Server GO/GO N、错误策略和源行定位。
- 新增数据库工具窗口：CSV 字段映射导入、整表导出、对象设计器、基础结构比较、同名字段迁移、ER 图、单表查询构建、基础逻辑备份与 SQL 恢复。
- 当前结果增加 SQL INSERT 导出、大文本/时间字段详情；导出使用临时文件替换，取消不覆盖已有文件。
- 增加 TDengine 分批写入、子表归属、标签/超级表/子表/TTL 设计、版本能力探测及查询结果折线图与 SVG 导出。
- 增加 SSH 密码/私钥隧道、SHA256 主机密钥固定、SSH 凭据加密、独立口令配置备份、连接池设置及连接检测。
- 增加自定义 SQL 模板管理、字体/快捷键、分栏记忆、加密分级日志、执行计划与上下文字段补全。
- 增加离线脚本、CSV、文件原子替换、配置备份、TDengine 协议及设计器/图表无头 UI 回归。Release 共 133 项检查通过。
- 依赖漏洞检查发现 SSH.NET 与 DBus 旧版本公告后，升级 SSH.NET 2026.0.0、Tmds.DBus.Protocol 0.21.3；再次联网检查未发现已知漏洞。
- 提供六种 RID 发布脚本和三平台 CI 配置。当前实际生成 Windows x64 包，实库/SSH/其他平台验收仍待环境。

基础逻辑备份和结构比较的具体范围见 [功能进度](功能进度.md)，不等同于完整服务器备份或全对象同步。

## 0.2.0 · 在线数据编辑

- 有主键的 MySQL、PostgreSQL、SQL Server 普通表支持单元格编辑、新增、删除及 NULL。
- 维护独立查询页草稿，支持撤销和关闭提示；未处理草稿时阻止刷新、翻页及更换连接。
- 根据原始主键及行快照生成参数化 DML，批量放入单个事务；冲突、异常、取消均回滚。
- 识别自增、identity、serial、计算列和 rowversion；防止对无主键表、视图和 TDengine 误用关系型编辑。
- 区分未填写字段与显式 NULL，保留服务器默认值；空结果保留列类型。
- 保护 COMMIT 回执边界；提交结果未知时禁用再次提交；提交成功后刷新失败不会保留可重复发送的变更。
- 修复 DataRowView 重载索引器导致表格空白的问题；新增可观察行适配，保留数字排序和行身份。
- 增加编辑会话、参数化 SQL、事务故障、ViewModel 状态、真实 Avalonia 单元格交互回归检查。

真实数据库服务器尚未接入，以上数据库交互仍需实库验收。SSH、CSV 导入、时序图表及 V1.0 专业能力仍在后续计划中。
